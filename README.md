# Speech Emotion Recognition 🎤

## Project Overview

Speech Emotion Recognition is a deep learning project that identifies human emotions from speech audio. The project uses **MFCC (Mel-Frequency Cepstral Coefficients)** for extracting speech features and a **Convolutional Neural Network (CNN)** for emotion classification.

## Technologies Used

* Python
* TensorFlow / Keras
* Librosa
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab

## Methodology

1. Collect speech emotion data
2. Preprocess the audio files
3. Extract MFCC features
4. Train a CNN model
5. Evaluate the model
6. Test the model with a WAV audio file
7. Predict the emotion

## Model Performance

* **Test Accuracy:** 48.96%
* **Test Audio:** `test_emotion.wav`
* **Predicted Emotion:** Sad

## Project Files

* `speech_emotion_cnn (1).h5` — Trained CNN model
* `emotion_recognition_model.keras` — Saved Keras model
* `emotion_label_encoder.pkl` — Label encoder
* `.ipynb` — Google Colab notebook
* `test_emotion.wav` — Test audio file

## Features

* Speech audio processing
* MFCC feature extraction
* CNN-based emotion classification
* Confusion matrix visualization
* Training and validation accuracy graphs
* Training and validation loss graphs
* Audio emotion prediction

## Conclusion

This project demonstrates how deep learning and speech signal processing can be used to recognize emotions from human speech. The CNN model successfully processes extracted MFCC features and predicts emotions from audio input.
